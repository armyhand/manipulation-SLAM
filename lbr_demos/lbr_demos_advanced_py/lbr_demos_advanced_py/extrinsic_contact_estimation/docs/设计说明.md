# 设计说明：外部接触的因子图优化估计与主动偏转

## 1. 背景与问题

机器人用夹爪夹持物体、并把物体压向环境（桌面、边缘、孔等）时，物体与
环境之间的接触称为**外部接触（extrinsic contact）**；夹爪手指与物体之间的
接触称为**内部接触（intrinsic contact）**。本任务的目标是：**在接触发生后，
仅依据触觉（Tac3D marker 位移/分布力）与夹爪运动学，对接触几何进行因子图
优化估计，并据此选择主动偏转的旋转中心与旋转方向，实现接触点/线的稳定估计。**

对应文献与借鉴：

1. **Simultaneous Tactile Estimation and Control of Extrinsic Contact**
   (S. Kim, D. K. Jha, D. Romeres, P. M. Patre, A. Rodriguez; ICRA 2023,
   arXiv:2303.03385)。提供因子图估计框架：
   `F_tac`(触觉位移)、`F_oc`(接触在物体系不变)、`F_cc`(接触在世界系缓变)、
   `F_torq`(接触处力矩约束)、`F_wr`(力矩回归)、`F_motion`/`F_rot`(主动偏转)。
   论文明确区分点/线/面（patch）接触并给出各自的力矩约束。

2. **TEXterity: Tactile Extrinsic deXterity**
   (A. Bronars, S. Kim, P. Patre, A. Rodriguez; arXiv:2401.10230 / 2403.00049)。
   提供离散（Viterbi 滤波）+ 连续（ISAM2）两层的估计-控制结构，以及
   极限面（limit-surface）摩擦模型与摩擦锥互补条件。

3. 既有工程实现
   `/home/armyhand/contact_point_estimation_and_scene_reconstruct/robot_pivoting_estimate/`
   下的 `gtsam_tactile_factor_graph.py`（点接触因子图）、
   `contact_line_factor_graph.py`（线接触因子图）、`slipping_detection.py`（滑移检测）、
   `contact_analysis.py`（旋转中心估计），以及实时节点
   `pose_planning_node_realtime_contact_line.py`。

本包在既有线接触因子图基础上，扩展为**统一的点/线/面接触因子图**，并新增
**接触类型分类器**与**旋转中心/方向选择器**，形成完整的主动偏转估计闭环。

## 2. 接触类型与几何参数化

接触类型由接触几何的“维度”决定：

| 类型 | 几何参数化 | 自由度数（约束后） |
|------|-----------|-------------------|
| 点接触 POINT | 接触点 `c ∈ R³` | 位置 3 维 |
| 线接触 LINE   | 线上一点 `p ∈ R³` + 单位方向 `u ∈ R³` | 位置沿线的冗余 1 维 + 方向 2 维 |
| 面接触 SURFACE| 面上一点 `p ∈ R³` + 单位法向 `n ∈ R³` | 位置沿面的冗余 2 维 + 法向 2 维 |

单位约定与既有代码一致：**位置/点在 mm，旋转角在 rad，力在 N，力矩在 N·mm**。

### 2.1 接触类型判别：力矩模型

接触体施加在物体上的合力/合力矩（夹爪系测量）记作 `(f, m)`，折算到接触点处：

```
m_c = m − (c_g − η) × f
```

其中 `c_g` 为接触几何在夹爪坐标系中的位置，`η` 为夹爪系力矩折算原点
（本实现取 `[0,0,223] mm`，即夹爪法兰/测量原点）。不同接触类型对 `m_c` 的约束
不同——这正是论文的核心判别依据（文献 1 的 Eq. 9）：

- **点接触**：接触为理想点，只能传递力，不能传递力矩，
  `m_c = 0`（三维全零）。
- **线接触**：接触为一条线（如圆柱侧面贴边），可传递绕线的摩擦扭矩，
  但**绕接触线方向无扭矩**：
  `m_c · u = 0`（仅约束沿线分量，垂直于线的分量自由）。
- **面接触（patch）**：平面接触可传递面内合力和绕面内两轴的力矩，
  但理想情况下**绕面法向无扭矩**：`m_c · n = 0`。

### 2.2 接触类型判别：触觉几何形状

Tac3D 传感器上载荷集中区域（活跃 marker 点云）的空间形状与接触类型对应：

- **点接触**：活跃区为紧凑团簇（PCA 主轴半径小）；
- **线接触**：活跃区沿一条线拉长（PCA 主轴大、次轴/主轴小）；
- **面接触**：活跃区在二维平面内展开（主轴、次轴都大、第三轴小）。

本包用 `tactile_features.contact_patch_geometry` 对活跃 marker（按位移范数
取 top-N）做去中心 PCA，得到奇异值 `σ1≥σ2≥σ3`，再提取：
`extent=σ1`、`elongation=σ2/σ1`、`planarity=σ3/σ2`。

## 3. 因子图建模

因子图（GTSAM ISAM2）中的变量（世界/机器人坐标系）：

```
o_i ∈ SE(3)               物体位姿（第 i 帧）
c_i ∈ R³                  接触点（点接触）
p_i ∈ R³, u_i ∈ R³        接触线上一点与方向（线接触）
p_i ∈ R³, n_i ∈ R³        接触平面上一点与法向（面接触）
w   ∈ R³                  夹爪系力矩折算原点（共享）
μ   ∈ R                   摩擦系数（可选，用于诊断）
```

因子汇总（符号沿用既有代码与文献 1）：

| 因子 | 含义 | 残差 |
|------|------|------|
| `Ftac` | 触觉位移测量 | `se3_log(g_i⁻¹ o_i) − δ_i` |
| `Foc`  | 接触几何在物体系不变（相邻帧） | 点：`(o⁻¹c)_i − (o⁻¹c)_{i-1}`；线/面：几何量在物体系的差 |
| `Fcc`  | 接触几何在世界系缓变（相邻帧） | 点：`c_i − c_{i-1}`；线/面：几何量在世界系的差 |
| `Fsurf`| 接触点/线落在已知环境平面 | 点到平面的带符号距离 |
| `Ftorq`| 接触处力矩约束（按类型） | 见 §2.1 |
| `Fwr`  | 触觉位移回归力/力矩（可选） | `[m,f] − K·se3_log(g⁻¹o)` |
| `Ffric`| 摩擦力锥软约束（可选/诊断） | `max(0, |f_t| − μ|f_n|)` |
| 先验   | 物体位姿、接触几何初值、共享原点 | — |

### 3.1 各因子残差

**Ftac（触觉位移）**

触觉 marker 的位移经 Kabsch 刚体配准解出“物体相对夹爪的位移变换”`T_tac ∈ SE(3)`，
由此：

```
r_ftac = se3_log(g_i⁻¹ o_i) − se3_log(T_tac,i)   ∈ R⁶
```

**Foc（接触几何在物体系不变）**

以线接触为例，把世界系接触线 `(p, u)` 变换到物体坐标系：

```
(p', u') = line_in_pose_frame(o, p, u)
r_foc = [ (p'_i − p'_{i-1}) − u'̄·((p'_i − p'_{i-1})·u'̄) ,  u'_i − u'_{i-1} ]  ∈ R⁶
```

其中 `u'̄ = normalize(u'_i + u'_{i-1})`，线上点残差取“垂直于平均方向”的分量，
以消除沿直线方向的冗余自由度。

**Fcc（接触几何在世界系缓变）**

```
r_fcc = [ (p_i − p_{i-1}) − ū·((p_i − p_{i-1})·ū) ,  u_i − u_{i-1} ]  ∈ R⁶
```

**Fsurf（已知环境平面）**

环境平面 `(p_s, n_s)` 已知时（例如桌面高度），约束：

- 点接触：`r = n_s·(c − p_s)`（点到平面的距离）
- 线接触：`r = [n_s·(p − p_s), n_s·(p + u − p_s)]`（线上两点在平面内）

**Ftorq（接触处力矩约束，核心判别因子）**

夹爪系合力 `f`、合力矩 `m`，接触几何在夹爪系的位置 `c_g`、方向 `u_g`、法向 `n_g`：

```
m_c = m − (c_g − η) × f
点接触：  r = m_c                       ∈ R³
线接触：  r = m_c · u_g                 ∈ R¹   （沿线无摩擦扭矩）
面接触：  r = m_c · n_g                 ∈ R¹   （绕法向无扭矩）
```

使用 Huber 鲁棒核处理接触切换（点→线→面）时的残差突变，从而在**接触类型
判别错误时估计不至于发散**。

**Fwr（触觉位移回归，可选）**

```
r_fwr = [m, f] − K·se3_log(g_i⁻¹ o_i)  ∈ R⁶
```

其中 `K = diag(κ_x,κ_y,κ_z, k_x,k_y,k_z)` 为抓持刚度（旋转部分与平移部分量纲
不同）。实时管线直接读取合力矩时该因子可不使用。

### 3.2 噪声模型

噪声模型（σ，单位 mm / rad）与既有 `contact_line_factor_graph.py` 保持一致，
点接触的 3 维 Foc/Fcc 残差使用匹配维度的模型：

| 因子 | 噪声 |
|------|------|
| Ftac | 平移 0.004，旋转 0.35 |
| Foc（线/面 6 维） | 点 0.8，方向 0.015 |
| Foc（点 3 维） | 0.8 |
| Fcc（线/面 6 维） | 点 0.35，方向 0.006 |
| Fcc（点 3 维） | 0.35 |
| 单位长度 | 0.003 |
| Ftorq | Huber(1.345) + 高斯 σ=10 |
| 物体位姿先验 | 平移 0.01，旋转 0.6 |
| 接触点先验 | 20 |
| 接触方向先验 | 0.15 |
| 共享原点先验 | 30 |

### 3.3 估计不确定度

对增量因子图，`gtsam.Marginals` 可从累积图与当前估计提取接触点/方向的
**边际协方差** `Σ`。位置不确定度取：

```
σ_pos = sqrt(max(diag(Σ_c)))
```

该值用于 §4 的主动偏转角度决策：不确定度越大，单步偏转角越大（获取更多信息）。

## 4. 主动偏转：旋转中心与旋转方向选择

对应文献 1 的 `F_motion`（“惩罚估计接触点处的局部运动”，使被命令的旋转在
接触点处实现为绕接触几何的转动）。目标是：**保持接触不变的前提下旋转，
最大化触觉信息增益，避免滑移，并平衡绕不同轴的力矩。**

### 4.1 旋转轴选择（按接触类型）

- **线接触**（本任务主工况）：旋转轴 = 估计接触线 `(p, u)`，
  中心点取线上离夹爪参考最近的点（`point_on_line`）。绕线旋转时接触线
  保持不变，物体绕线摆动——与现有 `As_planner` 的定轴旋转一致。
- **点接触**：旋转轴 = 过接触点 `c` 的直线，方向取垂直于“点 `c` 到物体中心
  杠杆臂”的方向 `u₁ = normalize(lever × a)`，并在两个正交轴
  `u₁`、`u₂ = u₁ × lever̂` 之间交替（dither），最大化 marker 位移且保持 `c` 固定。
- **面接触**：旋转轴 = 过接触区重心、位于接触面内的方向
  `u = n × lever`，交替滚动，保持平面贴合。

### 4.2 旋转角度与方向

```
θ = clamp(gain · σ_pos, θ_min, θ_max)      # 不确定度越大，偏转越大
θ = θ · (1 − k·max(0, slip−slip_thr)/slip_thr)   # 滑移接近阈值时缩减
sign = compensated_rotation_sign(m_g, u, sign_prev)  # 力矩补偿
```

- `θ_min = 1.5°`, `θ_max = 10.0°`, `gain = 1.5 rad/mm`（默认，可调）。
- **力矩补偿**：当夹爪合力矩在旋转轴方向的分量显著（`|m_g·u| > 8 N·mm`）且
  与当前旋转同向时取反号，避免绕某轴力矩持续增大（对应源码注释第 7 条）。

### 4.3 接触类型切换的鲁棒性

当接触从点→线（或线→面）切换时，`Ftorq` 残差会突变，Huber 核抑制其影响；
分类器会随着几何证据变化重新分类，下一次迭代采用新类型的因子图。
这对应文献 1 的“通过监测力矩残差增量检测形成切换”的思路。

## 5. 模块与数据流

```
TactileSnapshot（npz 或 ROS 话题缓存）
        │
        ▼
┌─────────────────┐
│ data_io         │ 位姿(mm)、合力/合力矩、触觉相对变换、接触线/点初值
└─────────────────┘
        │
        ▼
┌─────────────────┐
│ tactile_features│ 活跃 marker 点云 PCA 特征（extent/elongation/planarity）
└─────────────────┘
        │
        ▼
┌─────────────────┐
│ contact_classifier│ 几何 + 力矩证据融合 → 接触类型
└─────────────────┘
        │
        ▼
┌─────────────────┐
│ factor_graph_estimator│ GTSAM ISAM2 统一因子图（点/线/面）
│                      │ → 接触几何 + 边际协方差
└─────────────────┘
        │
        ▼
┌─────────────────┐
│ rotation_selector│ 旋转中心 + 旋转方向 + 角度/方向决策
└─────────────────┘
        │
        ▼
RotationCommand（center_point, axis_direction, angle, sign）
```

`ActiveProbingPipeline.feed_snapshot` 串起以上各步，返回
`ContactProbingResult`（分类、估计、旋转指令、诊断）。

## 7. 局限与后续

- 线接触线上点的“沿线位置”本质不可观（直线上滑移不改变线本身），
  表现为该方向的边际协方差较大（离线实测约 19 mm）。命令端使用
  “线上离夹爪最近点”作为旋转中心以规避该冗余。
- 摩擦系数 `μ` 尚未作为变量加入因子图，仅在分类/角度约束中使用；
  可借鉴 TEXterity 的极限面模型把 `μ`、`F_max/M_max` 作为可优化变量。
- `Fsurf` 依赖环境平面的粗略先验；可通过首次接触的平面拟合自动初始化。
