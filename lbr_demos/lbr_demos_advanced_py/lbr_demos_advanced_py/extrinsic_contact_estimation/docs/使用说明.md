# 使用说明

## 1. 运行环境

推荐使用 ROS2 Humble 自带的 `/usr/bin/python3`（含 gtsam），或任意 Python 3.10+：

```bash
# 检查依赖
/usr/bin/python3 -c "import numpy, scipy, gtsam; print('deps ok')"
# 绘图（可选）
/usr/bin/python3 -c "import matplotlib; print('matplotlib ok')"
# ROS 实时节点（可选）
source /opt/ros/humble/setup.bash
/usr/bin/python3 -c "import rclpy; print('rclpy ok')"
```

缺少 `gtsam` 时安装：`/usr/bin/python3 -m pip install --user gtsam`。

包内代码只依赖 `numpy/scipy`（`contact_models`、`tactile_features`、`rotation_selector`），
`gtsam` 仅在 `factor_graph_estimator` 实例化时导入，因此**无 gtsam 也可单独测试
残差、分类与旋转选择**。

## 4. 集成到实时节点

### 4.1 用 `ActiveProbingPipeline` 接入既有节点

在 `pose_planning_node_realtime_contact_line.py` 中，接触检测触发后
（对应现有 `_start_contact_line_estimation_async`），把节点内存缓存构造为
`TactileSnapshot` 并调用管道：

```python
from lbr_demos_advanced_py.extrinsic_contact_estimation import ActiveProbingPipeline

pipeline = ActiveProbingPipeline(
    frame_step=5,
    top_n=60,
    compute_covariance=True,          # 计算边际协方差以驱动偏转角度
    # surface_plane_point=np.array([0, 0, 0]),     # 已知环境平面（可选）
    # surface_plane_normal=np.array([0, 0, 1]),
)

# —— 每个控制周期，在填充 self.Pose/... 等缓存后 ——
def _update_probing(self):
    snapshot = self._make_snapshot()               # 见下
    if len(snapshot.Pose) - snapshot.contact_start_frame < 6:
        return
    try:
        result = pipeline.feed_snapshot(
            snapshot,
            slip_score=self.slip_score[-1] if self.slip_score else None,
            slip_threshold=self.slip_threshold,
        )
    except ValueError:
        return   # 帧数不足
    cmd = result.rotation_command
    # 用 cmd.center_point / cmd.axis_direction / cmd.effective_angle()
    # 替换现有 As_planner 中的 self.world_rotation_line_point/direction/angle，
    # 调用 generate_rotation_path_points 生成最小加加速度轨迹。
```

`_make_snapshot` 与现有 `_make_contact_line_snapshot` 等价：

```python
def _make_snapshot(self):
    return TactileSnapshot(
        contact_start_frame=int(self.contact_start_frame),
        Pose=self.Pose.copy(),
        Quat=self.Quat.copy(),
        Position_left=self.Position_left.copy(),
        Position_right=self.Position_right.copy(),
        Displacement_left=self.Displacement_left.copy(),
        Displacement_right=self.Displacement_right.copy(),
        Force_dis_left=self.Force_dis_left.copy(),
        Force_dis_right=self.Force_dis_right.copy(),
        F_x=self.F_x.copy(), F_y=self.F_y.copy(), F_z=self.F_z.copy(),
    )
```

**闭环策略建议**：

1. 接触检测（现有 slip/接触阈值）后启动；
2. 每轮：估计 → 由 `rotation_command` 生成绕接触线的偏转轨迹；
3. 轨迹执行中实时采集，缓存足够帧后再次估计；
4. 接触类型切换（点→线→面）时 `Ftorq` 残差会突变，分类器自动更新类型；
5. 滑移分数接近阈值时角度自动缩减（`clamp_angle_by_slip`）；
6. 迭代若干轮后 `position_std` 收敛，偏转角减小，接触进入稳态。

## 5. 参数调优指南

### 分类器（`ContactClassifier`）

| 参数 | 默认 | 作用 |
|------|------|------|
| `point_extent_mm` | 8.0 | 活跃区主轴半径小于该值判定点接触（mm） |
| `line_elongation` | 0.45 | 次轴/主轴比值小于该值判定线接触 |
| `surface_planarity` | 0.55 | 第三轴/次轴比值小于该值判定面接触 |
| `geometric_weight` | 0.7 | 几何证据权重（主） |
| `wrench_weight` | 0.3 | 力矩证据权重（辅） |

阈值偏大 → 更倾向判定高维接触（线/面）；阈值偏小 → 更倾向点接触。
真实数据在接触稳定帧（`contact_start_frame + 10`）的活跃区形状最具代表性。

### 旋转选择（`RotationSelector`）

| 参数 | 默认 | 作用 |
|------|------|------|
| `min_angle_deg` | 1.5 | 单步最小偏转角 |
| `max_angle_deg` | 10.0 | 单步最大偏转角 |
| `uncertainty_gain` | 1.5 | 不确定度(mm) → 角度(rad) 增益 |
| `max_slip_ratio` | 0.5 | 滑移过阈值时角度缩减系数 |

角度越大信息增益越大但越易滑移；`max_angle_deg` 需小于任务允许的摆动范围。
`uncertainty_gain` 增大使收敛更快、但后期步长更粗糙。

### 因子图（`ContactFactorGraphISAM2`）

噪声模型（`noise_*`）默认与既有 `contact_line_factor_graph.py` 一致，
可单独调整以平衡：
- 减小 `noise_fcc` 的平移 σ（0.35）→ 接触点在世界系更稳定；
- 增大 `noise_foc` 的方向 σ（0.015）→ 允许接触几何在物体系缓变（利于偏转）；
- `noise_torque` 的 Huber 阈值 1.345 → 越大越容忍接触类型失配残差。

`compute_covariance=True` 时每次 `current_estimate` 计算全图边际协方差，
帧数多时耗时增长；实时场景建议仅在偏转决策帧调用。

## 6. 常见问题

- **`NoiseModelFactor: NoiseModel has dimension ...`**：残差维度与噪声模型不匹配。
  点接触的 Foc/Fcc 为 3 维，Ftorq 为 3 维；线/面为 6/1 维。代码已内置匹配模型，
  修改时注意保持。
- **位置不确定度偏大（十几 mm）**：线接触“沿线位置”不可观，属正常现象；
  命令端用“线上离夹爪最近点”作为旋转中心。
- **分类结果在点/线之间抖动**：接触切换初期正常；可增大 `geometric_weight`，
  或在连续若干帧一致后再切换因子图类型（迟滞）。
- **离线图不生成**：确认 `matplotlib` 可用，且 `--out` 目录可写。
